# Plater-Nameplates (3.3.5a backport)
Plater-v576a backported to World of Warcraft 3.3.5a.

## Requirements
- WoW 3.3.5a client (interface 30300).
- A client-side nameplate API (`C_NamePlate`). Plater shows no nameplates without one:
  - FrostmourneRebuffed: already included (`rebuffed.dll`), nothing to install. Do not add awesome_wotlk on top.
  - Any other 3.3.5a client: install [awesome_wotlk](https://github.com/FrostAtom/awesome_wotlk).
- `!!!ClassicAPI` is not required.

## Install
Extract the release zip into `Interface\AddOns` so you get `Interface\AddOns\Plater\Plater.toc`, then `/reload` and type `/plater`.
